    Lieber Telegram?

    Wenn du Telegram sowieso nutzt, brauchst du gar keine neue App. Setz oben den Haken bei „Auch per Telegram“. Nach dem Anmelden bekommst du einen Knopf, der Telegram beim Bot öffnet und deinen Code abschickt. Mehr ist es nicht: keine Chat-ID heraussuchen, kein Warten auf jemanden, der dich freischaltet.

    Beides gleichzeitig geht auch. Dann kommen die Meldungen auf die ntfy-App und nach Telegram, etwa aufs Handy und aufs Tablet.

    Warum das so gut klappt

    Das Radar sagt nichts vorher. Es sieht, wo der Regen gerade wirklich steht, auf einen Kilometer genau und alle fünf Minuten neu, und rechnet aus, wohin er zieht. Für die nächste Stunde schlägt das jedes Vorhersagemodell. Danach übernehmen die Modelle.

    DWD-Radarsieht den Regen 2 Std
    ICON-D2DWD-Modell, 2 km 2 Tage
    MET NorwayZweitmeinung 2,5 Tage
    MOSMIXDWD-Stationen 10 Tage

    Für jedes Zeitfenster nimmt GleichNass den Dienst, der wirklich so weit sieht. Sagt einer nichts, wird das gemeldet. Ein Ausfall wird nie als „bleibt trocken“ ausgegeben.

    Selber hosten

    GleichNass ist freie Software und läuft auf einem Raspberry Pi genauso wie auf einem kleinen Server. Der Quellcode liegt auf GitHub, unter der AGPL-3.0.

    Zum Quellcode 
    # einmal einrichten
git clone https://github.com/ribalba/gleichnass
cd gleichnass
docker compose up -d

    Danach gleichnass add-user --name "Didi" --place Konstanz, QR-Code scannen, fertig. Für Freunde gibt es eine Anmeldeseite, die Thema und QR-Code selbst erzeugt.
